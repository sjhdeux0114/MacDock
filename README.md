# MacDock

Windows 모니터의 하단·상단·왼쪽·오른쪽에 배치하는 매크로 독입니다. **독 설정 → 독 줄 수**에서 1~6줄을 선택할 수 있습니다. 위·아래에서는 행을, 좌우에서는 열을 늘립니다. 마우스를 가까이 가져가면 버튼이 확대되고, 프로그램·폴더·키 매크로·시스템 정보를 한곳에서 사용할 수 있습니다.

현재 배포 버전은 **WPF v0.6.2 / Windows x64**입니다. Deckboard나 Electron 없이 실행됩니다. Deckboard 확장은 지원하지 않습니다.

## 다운로드 및 실행

[최신 릴리스 다운로드](https://github.com/sjhdeux0114/MacDock/releases/latest)

| 파일 | 실행 방법 |
| --- | --- |
| MacDock-v0.6.2-win-x64-Setup.exe (권장) | 설치 마법사 실행. .NET 런타임 포함 |


설치 파일에는 실행에 필요한 .NET 런타임이 포함됩니다. Windows 10/11 x64용이며 모든 OS·장치 조합에서 검증된 것은 아닙니다. 현재 배포 파일은 코드 서명되지 않았습니다.

업데이트는 기존 독을 **트레이 메뉴 → 종료**로 닫고 새 버전을 실행하세요. 설정은 유지됩니다. 자동시작을 사용한다면 새 버전에서 **변경 저장**을 눌러 실행 경로를 갱신하세요.

설치 파일은 현재 사용자 계정의 `%LOCALAPPDATA%\Programs\MacDock`에 설치하며 시작 메뉴 바로가기를 만듭니다. 바탕화면 바로가기는 선택 사항입니다. Windows 설정의 설치된 앱에서 제거할 수 있으며 사용자 설정은 보존됩니다. 기존 자동시작이 활성화되어 있다면 설치 경로로 갱신됩니다.

설치 프로그램은 관리자 승인을 받아 설치된 MacDock의 파일 서버 포트(기본 8787/TCP)를 공용·개인 프로필의 로컬 서브넷에 허용합니다. 파일 서버 설정에서 포트를 변경하고 Windows 관리자 요청을 승인하면 기존 규칙이 새 포트로 갱신됩니다. 제거 시 설치 프로그램이 만든 규칙도 삭제됩니다.

## 파일 공유 서버

**MacDock 설정 → 파일 공유 서버**에서 공유 폴더를 선택하고 접속 비밀번호와 포트를 저장한 뒤 **서버 시작**을 누르세요. 같은 Wi-Fi의 휴대폰에서 탭에 표시된 주소로 접속하면 됩니다. 포트 변경은 서버를 중지한 뒤 다시 시작하면 적용됩니다.

**독 설정 → 빠른 추가 → 파일 공유 서버 → 변경 저장**으로 독에 바로가기를 추가할 수 있습니다. 독 버튼은 설정해 둔 서버를 시작하고 파일 공유 탭을 엽니다. 서버는 MacDock 프로세스 안에서 동작하므로 MacDock을 종료하면 공유도 종료됩니다. 로그인 시 자동 시작은 파일 공유 탭에서 설정할 수 있습니다.

설정은 기존과 같은 `%LOCALAPPDATA%\MacDock\FileShare\FileShare.ini`에 저장합니다. 파일 전송 서버와 웹 화면은 저장소의 [fileshare](fileshare) 소스에서 함께 빌드합니다. [원본 FileShare 0.4.0](https://github.com/sjhdeux0114/fileShareServer/tree/ff6b33bc119adb821c2e5313d727b0d52c27323e)

버튼마다 **블록 크기**를 선택할 수 있습니다. ×2는 가로 두 칸, 2×2는 두 줄 이상에서 가로·세로 두 칸씩 차지합니다. 큰 블록에는 칸 사이 간격이 포함됩니다. 한 줄로 줄이면 2×2는 가로 두 칸으로 표시됩니다.

실행 중 독의 여백이나 버튼 사이를 드래그하면 독 전체를 이동합니다. 버튼을 같은 페이지의 다른 버튼 위에 놓으면 해당 순서로 이동합니다. 위치와 순서는 놓는 즉시 저장되며, 설정에서 기본 가장자리 위치로 복귀할 수 있습니다.

각 독 버튼 설정 카드 하단의 **복제하기**는 현재 편집한 버튼을 바로 아래에 복사합니다. **변경 저장**으로 적용하세요.

## 사운드 재생과 타이머

**독 설정 → 빠른 추가**에서 **사운드 재생** 또는 **타이머**를 추가하세요. 내장 소리 50개(효과음 44개·완료 알람 6개) 또는 내 PC의 오디오 파일을 골라 미리 듣고 저장할 수 있습니다. 내장 샘플은 Kenney의 CC0 음원을 WAV로 변환한 것이며, 완료 알람은 짧은 음을 반복하도록 편집했습니다. [Interface Sounds](https://kenney.nl/assets/interface-sounds) · [Digital Audio](https://kenney.nl/assets/digital-audio)

타이머 시간은 버튼 설정에서 시·분·초로 지정합니다. 한 번 누르면 시작·일시정지·재개하고, 더블클릭하면 설정한 시간으로 초기화합니다. 남은 시간이 표시되고 버튼의 음영이 12시부터 시계 방향으로 걷히며, 다른 독 페이지를 보고 있어도 완료 알람이 울립니다. 완료된 타이머를 누르면 알람이 멈추고 설정한 시간으로 돌아갑니다. 다시 누르면 시작합니다. 타이머는 MacDock이 실행 중일 때 동작합니다.

## Windows 도구와 자동 종료

**독 설정 → 빠른 추가**에서 **제어판**, **장치 관리자**, **전원 관리**, **Windows 자동 종료** 중 필요한 버튼을 추가하고 **변경 저장**을 누르세요. 전원 관리는 제어판의 전원 옵션을 엽니다.

**Windows 자동 종료** 버튼을 누르면 종료까지 남은 시간과 분을 입력할 수 있습니다. 예를 들어 1시간 30분을 입력하고 예정 시각을 확인한 뒤 **종료 예약**을 누르세요. Windows가 예약을 관리하므로 MacDock을 닫아도 예약이 유지됩니다. 예약 중에 같은 독 버튼을 다시 누르면 Windows의 기존 종료 예약을 즉시 취소하고 메시지 박스로 알려줍니다.

## 시작하기

1. 독의 톱니바퀴 또는 트레이 아이콘에서 설정을 엽니다.
2. 모니터, 독 위치, 버튼 크기, 확대 배율, 간격과 가장자리 여백을 선택합니다.
3. **빠른 추가**에서 계산기·메모장·폴더·매크로·시스템 정보 버튼을 추가합니다.
4. 이름, 동작, 아이콘과 색상을 편집한 뒤 **변경 저장**을 누릅니다.

버튼이 많으면 독 위에서 마우스 휠 또는 ‹ / › 버튼으로 페이지를 전환합니다. 확대 효과는 설정에서 끌 수 있으며 Windows 애니메이션 설정도 따릅니다.

## 기능

- 선택한 모니터의 네 가장자리에 가로·세로 배치, 작업 표시줄 회피 및 화면 안쪽 방향 확대
- 웹사이트·프로그램·파일·지정 폴더 열기
- 계산기, 메모장, 그림판, 탐색기, 작업 관리자, Windows 설정 빠른 추가
- 폴더·프로그램·매크로 아이콘 아래 이름 표시, 긴 이름 말줄임
- 폴더 선택 시 마지막 폴더 이름 자동 입력 및 사용자 수정
- 내장 아이콘 40종, 색상표 24색, 사용자 이미지와 GIF
- 시계, CPU/RAM 사용률, NVIDIA GPU 사용량과 온도, 이더넷 UP/DOWN
- 키 매크로 녹화, 키 조합·대기·텍스트 입력
- 미디어 제어, 시스템 볼륨 올리기·내리기·음소거, 조절 폭 1~100%p 지정
- USB 저장장치 모두 안전하게 제거, 장치별 완료·실패 사유 표시
- Windows 로그인 시 자동시작 체크박스
- 설정 가져오기/내보내기, 트레이 메뉴, 중복 실행 방지

## USB 모두 안전하게 제거

설정 → **빠른 추가 → USB 모두 제거 → 변경 저장**으로 버튼을 추가하세요. 버튼을 누르면 USB 메모리·외장 HDD/SSD에 Windows 안전 제거를 요청하고 결과를 표시합니다. 사용 중인 장치는 강제로 해제하지 않습니다. 키보드·마우스·허브는 제거하지 않으며, Windows 드라이버가 안전 제거 대상으로 제공하는 USB 저장장치만 지원합니다.

## 키 매크로

**직접 매크로**를 누르거나 버튼 종류를 **키 매크로 / 텍스트**로 선택합니다. 한 줄에 한 단계씩 입력합니다.

```text
Ctrl+C
wait 300
Ctrl+V
text 안녕하세요
```

**키 녹화 → 녹화 시작**을 누르고 녹화 창에서 키를 입력하세요. **F8 또는 중지**로 끝내고 **입력에 적용**을 누릅니다. 다른 창으로 이동하면 녹화가 중지됩니다. 입력 사이 대기 시간을 포함할 수도 있습니다. Windows 키 조합은 `Win+Shift+S`처럼 직접 입력하세요. 녹화는 문자 받아쓰기가 아니므로 한글 문장은 `text` 명령으로 입력하세요.

매크로는 독을 클릭하기 전 사용하던 앱으로 전달됩니다. 관리자 권한 앱에는 Windows 권한 제한으로 입력이 차단될 수 있습니다. 최대 100단계, 대기는 단계당 10초·전체 30초입니다.

## 시스템 정보 지원 범위

| 버튼 | 측정 범위 |
| --- | --- |
| CPU / RAM | 시스템 전체 사용률, 약 1초 간격 |
| GPU / GPU 온도 | NVIDIA nvidia-smi의 GPU 0, 약 3초 간격. 현재 AMD/Intel 미지원 |
| 이더넷 UP / DOWN | 연결된 물리 유선 어댑터 합계, 약 1초 간격. Wi-Fi·VPN·가상 어댑터 제외 |

네트워크 단위는 초당 **바이트**이며 KB=1,000 B, MB=1,000,000 B입니다. 첫 측정 대기, 연결 끊김 또는 미지원 값은 `—`로 표시됩니다. 버튼에 마우스를 올리면 장치 정보를 확인할 수 있습니다. GPU 측정은 NVIDIA 드라이버가 설치한 시스템 폴더의 `nvidia-smi.exe`를 사용합니다.

## 설정과 자동시작

설정 위치: `%APPDATA%\MacDock.Wpf\settings.json`. 저장 시 이전 설정은 `settings.json.bak`으로 보관됩니다. Electron 설정과는 별도입니다. Electron JSON을 가져오면 확장 버튼은 제외됩니다.

**Windows 시작 시 자동 실행**을 체크하고 저장하면 현재 사용자 로그인 시 실행됩니다. 체크 해제 후 저장하면 제거됩니다. 배포 폴더의 위치를 먼저 정한 뒤 설정하세요.

이미지는 PNG/JPEG/GIF/BMP를 지원하며 WebP는 지원하지 않습니다. GIF는 최대 300프레임입니다.

## 개발 및 검증

Windows와 .NET 10 SDK가 필요합니다.

```powershell
dotnet build wpf/MacDock.Wpf.csproj -c Release
dotnet run --project wpf/MacDock.Wpf.csproj -c Release -- --settings
dotnet run --project wpf/MacDock.Wpf.csproj -c Release -- --self-test
dotnet run --project wpf/MacDock.Wpf.csproj -c Release -- --smoke-test
```

검증 결과는 `wpf/test-output/`에 저장됩니다. self-test는 파싱·설정·계산·이미지 검증 및 하드웨어 읽기를, smoke-test는 별도 프로필로 UI와 장치 읽기를 확인합니다. 실제 키 전송·볼륨 변경·로그인 자동시작 동작은 자동 검사하지 않습니다.
