# MacDock

Windows용 단독 실행 매크로 독. Deckboard를 실행하거나 설치할 필요가 없습니다.

## 현재 구현 (0.1 초기 프로토타입)

- 선택한 모니터 하단에 한 줄로 배치, 작업 표시줄 영역 제외
- 마우스 거리 기반 확대 및 켜기/끄기, 크기·배율·하단 여백 설정
- 버튼 추가/삭제/순서 변경, 색상·문자·이미지(GIF 포함)
- 웹사이트, 프로그램 실행, 파일/폴더 열기
- 실시간 시계(12/24시간), 전체 CPU 사용량, 메모리 사용량
- Windows SendInput 키 조합/순차 매크로/유니코드 텍스트 입력
- 재생·일시정지/이전·다음/정지/음소거/볼륨 제어
- 사용자별 설정 저장, 트레이 설정/종료, 중복 실행 방지
- 독립 Node.js 확장 호스트: 명시적으로 불러온 설정 없는 `execute(action, params)` 패키지 지원

## 개발 실행

Node.js 24 LTS와 Windows 환경에서:

```sh
npm ci
npm start
npm start -- --settings
npm test
npm run dist
```

독의 톱니바퀴 또는 트레이 메뉴에서 설정을 엽니다. 변경 후 **변경 저장**을 누르세요.
포터블 빌드 결과는 `dist/`에 생성됩니다. 설정은 Electron 사용자 데이터 폴더의 `settings.json`에 보관됩니다.

## 확장 호환 상태

**전체 Deckboard 기능/확장 호환을 구현한 상태가 아닙니다.** 현재 프로토타입은 공개된 확장 계약의 일부만 지원합니다. 기존 Deckboard 앱 코드와 자산을 포함하지 않습니다.

설정에서 `examples/hello-extension` 폴더를 불러와 단독 실행 경로를 시험할 수 있습니다. 실제 확장은 자체 의존성이 설치되어 있어야 합니다. 확장은 신뢰하는 개발자의 코드만 불러오세요. 현재 확장 코드는 메인 프로세스 권한으로 실행되며 샌드박스가 아닙니다. 재시작 시 자동 실행되지 않으므로 다시 불러와야 합니다.

키 매크로는 한 줄에 `Ctrl+C`, `wait 300`, `Ctrl+V`, `text 안녕하세요`처럼 입력합니다. 독은 포커스를 가져오지 않아 기존 활성 앱이 입력을 받습니다. 관리자 권한으로 실행 중인 대상 앱에는 Windows의 권한 제한으로 입력이 차단될 수 있습니다. 미디어 명령은 Windows의 현재 미디어 세션을 제어합니다.

다음 작업: 별도 프로세스 확장 호스트, `.asar` 설치/목록, 설정·인증·상태 갱신 호환, OBS 등 내장 연동, Deckboard 보드 가져오기, 실제 확장별 호환 시험. 상세 범위는 [호환성 계획](compatibility.md)을 참고하세요.

MacDock은 Deckboard와 독립적인 프로젝트이며 공식 제품이 아닙니다.
